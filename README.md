## StockCheck（库存盘点系统）
### 一、功能清单
1.	商品管理
2.	库存查询
3.	创建盘点任务
4.	盘点录入
5.	差异计算
### 二、API 任务说明
•	GET /api/products
•	POST /api/checks
•	POST /api/checks/{id}/items
•	GET /api/checks/{id}/diff
### 三、开发步骤指引

•	差异计算正确
•	数据结构合理
### 五、数据库 SQL
```
CREATE TABLE stock_check (
    id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    create_time DATE DEFAULT SYSDATE,
    status VARCHAR2(20) DEFAULT 'NEW'
);
COMMENT ON TABLE stock_check IS '盘点任务表';
COMMENT ON COLUMN stock_check.id IS '主键ID';
COMMENT ON COLUMN stock_check.create_time IS '创建时间';
COMMENT ON COLUMN stock_check.status IS '盘点状态';
CREATE TABLE stock_check_item (
    id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    check_id NUMBER NOT NULL,
    product_id NUMBER NOT NULL,
    system_qty NUMBER NOT NULL,
    real_qty NUMBER,
    diff_qty NUMBER
);
COMMENT ON TABLE stock_check_item IS '盘点明细表';
COMMENT ON COLUMN stock_check_item.id IS '主键ID';
COMMENT ON COLUMN stock_check_item.check_id IS '盘点任务ID';
COMMENT ON COLUMN stock_check_item.product_id IS '商品ID';
COMMENT ON COLUMN stock_check_item.system_qty IS '系统库存数量';
COMMENT ON COLUMN stock_check_item.real_qty IS '实际盘点数量';
COMMENT ON COLUMN stock_check_item.diff_qty IS '差异数量';
```
